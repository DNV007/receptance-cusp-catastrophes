# reproduce.md — script-to-claim map

**Manuscripts covered by this deposit:**

- **(L)** K. Sarkar, *Linear Response Predicts Cusp-Pair Births in Networks
  with a Localized Cubic* (Letter, submitted to Physical Review Letters) —
  Letter, End Matter, and Supplemental Material.
- **(X)** K. Sarkar, *Pole-organized cusp catastrophes in locally nonlinear
  resonator networks* (submitted to Physical Review X).

The two are submitted **jointly** as a Letter and its companion long paper.
They share one code base and therefore one deposit.

The two manuscripts share one code base, so they share one deposit. Each entry
below is tagged **(L)**, **(X)**, or **(L,X)** when both quote it. Each entry
names the claim as it appears in the manuscript, the script that produces it,
and the value that script returns. No number in either manuscript was entered by
hand; each is regenerated by the script listed here.

---

## 1. Environment

- **Python** 3.11.5
- **numpy** 2.4.6, **scipy** 1.17.1, **jax** 0.10.2, **jaxlib** (matching
  jax), **matplotlib** 3.11.1
- All runs use the pinned interpreter at `.venv/bin/python`. Reproduce the
  environment from `pyproject.toml` / `uv.lock`.

> **Interpreter caveat.** In this environment the system Python interpreters
> break either `jax` or `scipy` when both are imported. Always invoke scripts
> as `./.venv/bin/python scripts/<name>.py`. The figure scripts that need both
> capabilities (e.g. `make_fig_prl_construction.py`) reimplement the receptance
> and root-finding in numpy alone for exactly this reason; this is documented
> in their headers.

**Self-contained.** The scripts in this deposit reproduce both manuscripts with
only the packages above; they do not import any external project package, and
no script requires `pandas`. (The broader research repository contains further
exploratory scripts that depend on the separate package `hh-antiresonance`;
those are not part of this deposit and are archived separately.)

**Core library modules** (imported by many scripts):

| module | role |
|---|---|
| `scripts/ndof_hb.py` | multi-harmonic-balance residual for the N-DOF network |
| `scripts/cusp_tip_intercept.py` | (ΔF)^{2/3} tongue-width cusp-tip estimator (never solves at the tip) |
| `scripts/arclength_fold.py` | pseudo-arclength fold continuation |
| `scripts/recompute_beaks_table.py` | closed-form (modal) receptance and cusp locus |
| `scripts/kerr_inverse_design.py` | coupled-mode (Kerr) receptance and device-unit solver |
| `scripts/_prx_style.py` | shared journal figure styling |

Some script docstrings mention an `hh_cusp` normal-form package from the
broader research repository. It is **not** required here and is not shipped:
every deposited script resolves its imports within `scripts/` and the pinned
third-party packages above.

**A naming note on damping.** Both manuscripts write γ for a damping *rate*
(the half-width in the lightly damped limit), not a dimensionless ratio. Some
older scripts name the same quantity `z`/`zeta`; they use it as a rate in the
denominator `ω² − Ω² + 2i·z·Ω`, so the numbers agree with the γ convention and
only the variable name differs.

## 9. Notes

- **Two determinations of the projection fold.** κ\*_HB = 0.119322 (long paper,
  convergence study) and 0.1193149 (Letter, single run) are both correct and
  their brackets overlap. They are not to be reconciled; see §6.
- **Rungs are coexisting pairs.** Ladder height is (max cusp count − 1)/2, never
  the number of times the count stepped up. The cusp count is non-monotonic in κ
  (13/24 nets in the 24-network set, 60/100 in the long paper's), so the event
  tally overstates the height and can manufacture apparent violations of the P−1
  bound. Both `ensemble_unified.py` and `ensemble_validity_boundary.py` print
  both measures with the wrong one labelled.
- **One ensemble, two results.** `ensemble_validity_boundary.py` (seed
  20260811, N = 3…6, 25 each) supplies BOTH the long paper's ladder counts and
  its phase-resolved validity boundary. They are not independent tests of one
  another. Its seed is independent of `ensemble_unified.py` (the 24-network
  N = 3, 4 set, archive only since 2026-09-07) and of nothing else.
- **Modal vs exact receptance.** `recompute_beaks_table.py` carries the modal
  (proportional-damping) form of Eq. (21); everything compared against harmonic
  balance uses the exact e₁ᵀZ⁻¹e₁. The two differ by ~0.5% in κ\* at the
  baseline and by ~6% at ω₂ = 0.95.
- Every reported number was regenerated from these scripts; no figure was
  generated or modified by generative AI (see the manuscript acknowledgments
  and generative-AI disclosure).
